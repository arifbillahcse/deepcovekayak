# Deep Cove Kayak — Group Programs Landing Page

A redesigned, animated landing page for Deep Cove Kayak's Team Building & Group
Programs, built as a single self-contained static site.

## Files
- `index.html` — page markup (hero, grouped inquiry form, steps, policies, footer)
- `styles.css` — full design system + responsive layout + animations
- `script.js` — scroll reveals, progress bar, count-up, form UX

## Design System
- **Colors:** Ocean Teal `#0D9B8A`, Deep Navy `#0B2A3B`, Warm Amber `#F5A623`,
  Off-White `#F7F9F8`, Slate ink `#1A2B2E`.
- **Type:** Montserrat (display/headings) + Inter (UI/body), via Google Fonts.
- **Motion:** Ken-Burns hero, floating blobs, scroll-reveal, SVG line-draw icons,
  animated count-up, ringing phone icon. Respects `prefers-reduced-motion`.

## Images
Photos are hot-linked from Unsplash (free license). Swap the URLs in
`index.html` for the studio's own photography before going live.

## Run
Open `index.html` in any browser — no build step required.
